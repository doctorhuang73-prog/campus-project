校园助手 iOS 初版：原生课表、成绩、学校网页登录和校方选课入口。

**Campus-unsigned.ipa 是未签名真机包，需要在 Windows 使用 Sideloadly 以自己的 Apple ID 重签安装，不能直接点击安装。** 免费签名通常 7 天有效，需续签。不需要把 Apple ID 密码交给本仓库或 GitHub Actions。

首次启动展示明确标注的演示数据。进入设置填写 HTTPS 教务根地址和学期，再打开学校登录页面；完成登录后点击“登录后同步”。初版原生同步仅支持新正方通用接口，未完成用户学校实测。强智、旧正方、金智、乘方和安卓插件尚未移植。

此 Release 仅在核心单元测试、iOS 模拟器构建与启动截图、iPhone 真机目标编译全部通过后自动发布。模拟器截图使用演示数据，不代表真实学校数据或真机选课验证。

初版通过学校原网页进行手动选退课，尚无自动抢课/捡漏队列、锁屏定时、小组件和通知。请阅读 README 和 docs/MIGRATION.md 了解迁移边界。

本项目不是原安卓作者发布的官方 iOS 版。上游来源与许可见 THIRD_PARTY.md，源代码按 GPL-3.0-or-later 发布。
